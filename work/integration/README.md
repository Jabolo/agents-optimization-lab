# The Agents Optimization Lab — case guide

This folder is a standalone case. Read `TASK.md` and the files it names, especially the visible contract. Use your own coding agent fully and work individually at your own pace. You may start any case immediately, complete just one decision loop, leave a partial result, or continue later.

Use the case to examine a tool or thinking habit you actually use. [PROMPT-CARDS.md](PROMPT-CARDS.md) gives optional examples for specific moments. Try one if it addresses a gap; retain your usual workflow if it already provides what you need. Judge actual consequences, including no difference or extra effort.

Choose a condition and a check; predict what result would support acceptance. Inspect the actual output and use the browser notebook in the complete packet or this case's `RESULT.md` to record the evidence, its limits, uncertainty and your decision: accept, reject, seek evidence, change approach or stop. Choose one record; there is no need to duplicate it. The optional [decision example](DECISION-EXAMPLE.md) illustrates the shape of a record in an unrelated situation. Note elapsed time and reliable usage/cost when available. Your agent may help at every step, but do not invent your habit, expectation or observation.

If this case has `NEXT.md`, record your current decision or what is still undecided before opening it. Then assess the report as a question, using evidence, and decide whether to retain or revise your decision. If your agent accessed it early, record that exposure; do not reconstruct a pre-report prediction or decision.

Python 3.11+ is needed for local checks. From this folder run `python3 smoke.py`; on Windows use `py -3 smoke.py`. A passing smoke is bounded evidence, not proof of the whole contract. For optional help see `support/READ-ME-FIRST.md` where present, or `FALLBACK.md`. Preserve your work and use a fresh extracted copy if you need a reset.
